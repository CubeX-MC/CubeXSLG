# 建筑模块 (Building)

## 包路径
`io.github.adlamb.cubex.feature.building` — `BuildingModule.kt`

---

## 概述

建筑模块处理所有与建筑相关的操作：获取建筑魔杖、放置预览、原理图粘贴、建筑交互（升级/移动/拆除/修复）以及建筑核心 GUI 入口。

---

## BuildingModule.kt

### 命令

| 命令 | 权限 | 功能 |
|------|------|------|
| `/slg wand <建筑>` | 无 | 获取指定建筑的魔杖工具，手持时显示放置预览 |
| `/slg repair` | 无 | 修复当前看向的建筑（消耗资源） |
| `/slg confirm` | 无 | 确认执行待操作（如拆除确认） |

### 事件监听

| 事件 | 处理逻辑 |
|------|----------|
| 玩家持魔杖右键方块 | 放置建筑：验证资源/城镇/位置 → 粘贴原理图 → 扣除成本 → 注册到数据库 |
| 玩家右键建筑核心 (Barrel) | 打开建筑管理 GUI（升级/移动/拆除/信息） |
| 魔杖粒子显示 | 每 tick 渲染放置预览（绿色=可放置，红色=不可放置） |

### 功能细节

- **魔杖预览**: 在目标位置渲染建筑大小的粒子盒轮廓，根据可放置性改变颜色
- **放置验证**: 检查城镇归属、领地范围、建筑上限、资源充足、方块空间
- **原理图粘贴**: 使用 `SchematicLoader.pasteSchematic()` 异步粘贴
- **建筑核心**: 每个建筑都有一个 Barrel 作为交互核心，右键打开操作菜单
- **升级/移动/拆除**: 通过 GUI 操作，调用 `GameplayFacade` 对应方法
- **修复**: `repair` 命令消耗资源恢复建筑耐久度

---

## 相关配置

`gameplay/buildings.yml` 定义了 11 种建筑类型，包括名称、魔杖材质、建造成本、产出/消耗配方、最大等级、升级成本和关联的原理图文件。
