# 资源模块 (Resource)

## 包路径
`io.github.adlamb.cubex.feature.resource` — `ResourceModule.kt`

---

## 概述

资源模块提供虚拟仓库的查看与统计功能。所有资源以数据库中的数字形式存储，无实物容器。玩家可以通过命令查看余额、统计信息和变动历史。

---

## ResourceModule.kt

### 命令

| 命令 | 权限 | 功能 |
|------|------|------|
| `/slg resources` | 无 | 打开仓库 GUI，显示所有资源的当前余额 |
| `/slg resources stats` | 无 | 显示资源统计信息（每秒净产量、总量等） |
| `/slg resources history` | 无 | 打开资源流水账，展示资源变动记录 |

### 事件监听

| 事件 | 处理逻辑 |
|------|----------|
| 无 | 纯命令驱动的信息查看模块 |

### 功能细节

- **实时余额**: 打开 GUI 时从数据库加载最新余额
- **分类显示**: 基础资源、加工资源、特殊资源分组展示
- **流水记录**: 所有资源变动（生产/消耗/建造/研究）均写入 `ResourceLedgerTable`，可追溯
- **统计概览**: 显示每秒净产量（总产出 - 总消耗）

---

## 资源分类

| 类别 | 资源 |
|------|------|
| 基础 (BASIC) | 木材、石头、矿石、粮食 |
| 加工 (PROCESSED) | 木板、石材、金属锭 |
| 特殊 (SPECIAL) | 科技点、居民口粮 |
