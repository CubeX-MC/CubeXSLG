# 管理模块 (Admin)

## 包路径
`io.github.adlamb.cubex.feature.admin` — `AdminModule.kt`

---

## 概述

管理模块提供服务器管理员所用的全部操作指令。需要 `cubexslg.admin` 权限。按功能分为城镇管理、建筑管理、居民管理、科技管理、数据管理五大类，共 18 个子命令。

---

## AdminModule.kt

### 权限

- `cubexslg.admin` — 执行所有管理命令

### 命令组 — `/slg admin <子命令>`

#### 城镇管理

| 子命令 | 参数 | 功能 |
|--------|------|------|
| `town list` | — | 列出所有已注册城镇及其 ID |
| `town info` | `<城镇>` | 显示指定城镇的详细信息（等级、成员、资源等） |
| `town delete` | `<城镇>` | 强制删除指定城镇及其所有关联数据 |
| `town transfer` | `<城镇> <玩家>` | 转让城镇所有权给另一位玩家 |
| `town setlevel` | `<城镇> <等级>` | 设置城镇等级 |
| `town addresource` | `<城镇> <资源> <数量>` | 为城镇添加指定资源 |

#### 建筑管理

| 子命令 | 参数 | 功能 |
|--------|------|------|
| `building list` | `<城镇>` | 列出城镇中所有建筑 |
| `building delete` | `<建筑ID>` | 强制删除指定建筑 |
| `building setlevel` | `<建筑ID> <等级>` | 设置建筑等级 |

#### 居民管理

| 子命令 | 参数 | 功能 |
|--------|------|------|
| `resident list` | `<城镇>` | 列出城镇所有居民 |
| `resident addattr` | `<居民ID> <属性> <值>` | 为居民添加或修改属性 |

#### 科技管理

| 子命令 | 参数 | 功能 |
|--------|------|------|
| `tech grant` | `<城镇> <科技>` | 直接授予指定科技 |
| `tech reset` | `<城镇>` | 重置城镇所有科技进度 |

#### 数据管理

| 子命令 | 参数 | 功能 |
|--------|------|------|
| `data reload` | — | 重新加载配置和数据文件 |
| `data stats` | — | 显示插件全局统计信息 |

#### 玩家管理

| 子命令 | 参数 | 功能 |
|--------|------|------|
| `player town` | `<玩家>` | 查看玩家所属城镇信息 |
| `player reset` | `<玩家>` | 重置玩家的游戏数据 |
