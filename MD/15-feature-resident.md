# 居民模块 (Resident)

## 包路径
`io.github.adlamb.cubex.feature.resident` — `ResidentModule.kt`

---

## 概述

居民模块管理城镇的居民系统。玩家可以招募具有随机属性的居民，查看居民列表，将居民分配到建筑中工作。居民系统为城镇提供劳动力资源。

---

## ResidentModule.kt

### 命令

| 命令 | 权限 | 功能 |
|------|------|------|
| `/slg residents` | 无 | 打开居民管理 GUI，列出城镇所有居民及其属性 |
| `/slg recruit` | 无 | 在玩家位置招募一名新居民（生成 Villager 实体） |

### 事件监听

| 事件 | 处理逻辑 |
|------|----------|
| 村民死亡 | 清理数据库中对应的居民记录 |
| 村民繁殖 | 阻止（防止自然繁殖破坏居民系统平衡） |
| 玩家与村民交互 | 阻止（通过交互 GUI 替代） |

### 功能细节

- **招募机制**: `GameplayFacade.recruit()` 生成一个 Minecraft Villager 实体
- **随机属性**: 每位居民有随机生成的属性值（如效率、力量等）
- **属性存储**: 以 JSON 格式存储在 `ResidentsTable.attributes_json` 字段
- **建筑分配**: 可将居民分配到建筑提升生产效率
- **数据库清理**: 村民死亡时自动清除数据库中对应的居民数据
