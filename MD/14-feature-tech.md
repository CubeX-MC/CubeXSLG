# 科技模块 (Tech)

## 包路径
`io.github.adlamb.cubex.feature.tech` — `TechModule.kt`

---

## 概述

科技模块实现科技树系统。玩家可以研究科技来解锁新建筑、获得生产倍率加成等。科技研究有前置条件、资源成本和城镇等级要求。

---

## TechModule.kt

### 命令

| 命令 | 权限 | 功能 |
|------|------|------|
| `/slg tech` | 无 | 打开科技树 GUI，显示已研究和可研究的科技节点 |

### 事件监听

| 事件 | 处理逻辑 |
|------|----------|
| 无 | 纯命令驱动的科技查看模块 |

### 功能细节

- **科技树 GUI**: 分分支展示所有科技节点，标记已研究/可研究/锁定状态
- **研究流程**: 选择节点 → 验证前置条件 → 验证城镇等级 → 扣除资源 → 解锁效果
- **效果应用**: 研究成功后立即应用生产倍率加成、建筑解锁等效果

---

## 科技分支

| 分支 | 描述 |
|------|------|
| AGRICULTURE | 农业——提高粮食产出 |
| ENGINEERING | 工程学——解锁高级建筑与加工效率 |
| MAGIC | 魔法——特殊科技加成 |
| MILITARY | 军事——防御与战斗相关 |
| CIVICS | 市政——城镇管理相关科技 |

---

## 相关配置

`gameplay/tech.yml` 定义了 11 个科技节点，包含名称、分支、前置科技、研究消耗、所需城镇等级、解锁内容和生产倍率加成。
